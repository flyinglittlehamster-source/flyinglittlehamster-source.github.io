MyGDSync 隐私政策

Privacy Policy · 更新日期 / Updated: 2026-10-23

本政策适用于 MyGDSync：在用户自己控制的 Mac 上运行、通过 Google Drive API（包括 rclone）同步、核验和归档本人文件的个人工具。本网站仅提供公开的应用说明与隐私政策。

1. 授权与访问的数据 / Data accessed

经用户主动通过 Google OAuth 授权，工具可以访问其 Google Drive 文件、文件夹名称、文件大小、校验和、文件 ID 等元数据，并根据用户配置对文件执行读取、上传、更新、组织或删除等操作。由于需要处理授权前已经存在的文件，所请求的 Drive 权限可能覆盖整个账户，而不仅限于本工具创建的文件；实际自动化任务限定在用户配置的工作目录与操作流程中。

2. 数据用途 / Purpose

只用于用户指定的本地与 Google Drive 同步、归档、恢复、完整性校验及操作日志。不会利用这些文件进行广告定向或出售个人数据。

3. 数据位置与传输 / Storage and transfer

文件可能保留在用户控制的 Mac 本地和用户本人授权的 Google Drive 账户中。OAuth 访问及刷新凭证由本地工具的配置机制保存于 Mac，不由本网站收集。Google API 通信由 Google 提供；本网站本身不接收 Drive 文件或访问令牌。

4. 分享与第三方服务 / Sharing

本工具不以广告、销售或资料交易为目的向第三方披露 Google 用户数据。为了执行同步，必要的文件和元数据会在本地设备与 Google Drive 之间传输；Google 自身依其服务条款处理相关数据。本公开说明网站由 GitHub Pages 托管，GitHub 可能依据其政策处理网站访问日志。

5. 保留、删除与撤销 / Retention and deletion

同步文件和日志依据用户的本地保留及 Google Drive 保存设置留存。用户可以在 Mac 上删除本地副本、在 Google Drive 中删除云端副本，并在 Google 账户第三方连接设置撤销应用授权。撤销授权不会自动删除用户已保存的本地文件或 Drive 文件；如需删除，仍需分别操作。

6. 本网站 / This website

此网页不提供账户注册、Google 登录或文件上传功能，也未嵌入自定义分析跟踪脚本。它可能包含指向 Google 和 GitHub 的链接，这些网站有独立的隐私政策。

7. 联系 / Contact

如对本个人工具的数据处理有疑问，可通过应用所有者 GitHub 主页联系。

8. 政策更新 / Updates

如果工具的访问范围、数据用途或存储方式发生实质变化，将更新本页面并注明日期。

English summary

MyGDSync is a personal, locally operated Mac utility for synchronizing and archiving files with the owner's Google Drive using Google Drive APIs and rclone. With the owner's OAuth consent, it may access Drive files and metadata and perform user-configured read/write operations on existing files. File contents remain on the owner's device and/or their Google Drive. OAuth credentials are kept in the local tool configuration and are not collected by this informational website. Data is not sold or used for advertising. Users can revoke access through Google Account settings and manage their local and Drive copies independently. This static site has no Google sign-in, file upload or custom tracking script. For questions, visit the owner's GitHub profile.
